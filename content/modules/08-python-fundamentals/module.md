Primer track de DataCamp de la ruta. Llegas con TypeScript de los módulos de libros, así que el objetivo es traducir lo que ya sabes a Python idiomático, no aprender a programar desde cero.

**Track:** [Python Programming Fundamentals](https://app.datacamp.com/learn/skill-tracks/python-programming-fundamentals) (skill track, 16 h listadas; 13 h de cursos).

**Cursos (en el orden del track):**

1. *Introduction to Python for Developers* (3 h) — sesiones 1–2.
2. *Intermediate Python for Developers* (2 h) — sesiones 2–3.
3. *Python Toolbox* (4 h) — sesiones 4–6.
4. *Data Types in Python* (4 h) — sesiones 7–8.

Después viene un proyecto propio (sesión 9) que junta colecciones, generators y funciones en una herramienta real, y una evaluación (sesión 10).

**Duplicados omitidos:** ninguno; este es el primer track. Sus cuatro cursos vuelven a aparecer en *Associate Python Developer* y *Python for Software Engineering*: allí no se repiten, porque DataCamp los marca como completados en todos los tracks.

**Cómo estudiar cada sesión `course`:** unos 90 minutos en DataCamp, luego 30 minutos de práctica activa: preguntas de repaso sin notas (active recall) y una explicación Feynman. Las preguntas entran a tu mazo de repetición espaciada.
