Quinto track de DataCamp. Casi todo ya lo completaste en los módulos 08, 10 y 11, así que este módulo es corto: solo los capítulos nuevos, un proyecto de refactorización y una evaluación integradora del track completo.

**Track:** [Python for Software Engineering](https://app.datacamp.com/learn/skill-tracks/python-for-software-engineering) (skill track, 32 h listadas; unas 3 h nuevas).

**Lo que haces aquí:**

1. *Writing Functions in Python*, capítulos 1 (*Best Practices*) y 4 (*More on Decorators*) — sesión 1. Los capítulos 2 y 3 ya los hiciste en el módulo 10.
2. *Writing Efficient Python Code*, capítulo 4 (*Basic pandas optimizations*) — sesión 2. Los capítulos 1–3 ya los hiciste en el módulo 11.
3. Proyecto: refactorizar `studylog` aplicando todo el track — sesión 3.
4. Evaluación del track completo — sesión 4.

**Duplicados omitidos:** *Introduction to Python for Developers* e *Intermediate Python for Developers* (módulo 08); *Introduction to Object-Oriented Programming in Python* (módulo 10); *Intermediate Object-Oriented Programming in Python*, *Data Structures and Algorithms in Python* e *Introduction to Testing in Python* (módulo 11); capítulos 2–3 de *Writing Functions in Python* (módulo 10) y capítulos 1–3 de *Writing Efficient Python Code* (módulo 11). DataCamp los marca como completados, así que el track debería quedar al 100 % con estas sesiones.
