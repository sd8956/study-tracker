Cuarto track de DataCamp y el más completo para tu perfil de desarrollador. No repite nada de los tracks anteriores.

**Track:** [Python Programmer](https://app.datacamp.com/learn/career-tracks/python-programmer) (career track, 28 h listadas).

**Elementos del track (en orden):**

1. *Writing Efficient Python Code*, capítulos 1–3 (los que incluye el track) — sesiones 1–2.
2. *Introduction to Git* (2 h) — sesión 3.
3. *Intermediate Git* (2 h) — sesión 4.
4. *Intermediate Object-Oriented Programming in Python* (4 h) — sesiones 5–7.
5. *Developing Python Packages* (4 h) — sesiones 8–10.
6. *Web Scraping in Python* (4 h) — sesiones 11–13.
7. Proyecto *Building a Calorie Intake Calculator* — sesión 14.
8. *Data Structures and Algorithms in Python* (4 h) — sesiones 15–18.
9. *Introduction to Testing in Python* (4 h) — sesiones 19–21.
10. Proyecto propio: CLI con pruebas — sesión 22.
11. Evaluación del track — sesión 23.

**Duplicados omitidos:** ninguno respecto a los módulos 08–10. Ojo: varios cursos de este track reaparecen en *Python for Software Engineering*, *Python Programming Toolbox* y *Data Structures and Algorithms in Python*; esos módulos no los repiten.

**Conexión con los libros.** *Data Structures and Algorithms in Python* es donde aprendes listas enlazadas, pilas, colas y ordenamiento: el módulo 01 los dejó para aquí. Las tablas hash, los heaps y los grafos ya los viste en el módulo 01; aprovecha para comparar.
