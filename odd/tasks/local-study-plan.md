# Feature: local study plan (books → DataCamp → Scrimba → Cloud)

Objective: turn the app into a local SQLite study planner. It covers the full route in the user's order, a daily English timer, in-app study guides that replace reading the books, spaced repetition, evaluations graded by an LLM (NaN Builders), and progress tracking.
Branch: `feat/local-study-plan` · Delivery: ask-on-risk · Test runner: vitest (`npm test`), plus `npm run typecheck`, `npm run lint`, `npm run build`.

## Specs

- **S1 Order.** "primero los libros que te pase y los repos, luego los cursos en el orden definido". Order: books + repos (system-design-primer, karanpratapsingh/system-design, Gentleman book) → DataCamp tracks in the given order → Scrimba fullstack path → "por ultimo la ruta que ya esta definida en este proyecto relacionado a cloud y seguridad en la nube". "no quiero dejar la ruta que ya existe quiero complementarla" — the 139-session Cloud route from `content/agenda.md` stays, as the last phase.
- **S2 Schedule.** "cada día espero estudiar 1 hora de ingles y 2 horas la ruta que defini, el sabado 1 hora de ingles y 3 horas la ruta, el domingo descanso." Sessions are sequential (a missed day does not skip anything; the next session waits). The app projects planned dates from the schedule (Mon–Fri 2 h, Sat 3 h, Sun rest).
- **S3 Books as study guides.** "necesito extraer de estos los temas agruparlos y que crees los conceptos, textos, resumenes a estudiar no quiero leer el libro como tal". Books are grouped by theme into modules. Each session is original study text, key concepts, review questions with model answers, an exercise and a Feynman prompt (`docs/CONTENT-FORMAT.md`). Never copy book passages; the PDFs in `Books/` are never committed.
- **S4 Learning technique.** Active recall, Feynman, spaced repetition and projects. "me gusta la tecnica de estudio que propones". "proyectos donde sea necesario". "puede que sea interesante agrar evaluaciones de los temas en ciertos puntos".
- **S5 Today view.** "quiero que estructures mi plan de estudio para que yo solo tenga que abrir la web ver que debo hacer hoy empezando por el ingles (ya tengo paga una plataforma así que debo hacer las clases aquí no hace falta tener temas) deberia tener un contador y luego un ruido que me indique que se acabo el ingles, luego de esto marcar que finalice el ingles del día y seguir con el plan de estudo tecnico donde tenga el tema o los temas del día estudiarlos y amrcar que lo hice". Sunday shows rest.
- **S6 Full route + tracking.** "donde pueda ver toda la ruta, marcar lo que ya hice cada día y tenga un seguimiento de lo que voy haciendo".
- **S7 Local SQLite.** "creo que podriamos usar qslite y ya". Supabase, magic-link auth, Vercel cron and the allowlist go away. The app runs locally, bound to 127.0.0.1, using `node:sqlite` (Node ≥ 22.5; the machine has v26).
- **S8 Tutor chat + voice.** "podriamos integrar un chat para evaluar mis respuestas incluso tengo acceso a un modelo de voz a texto, esto lo tengo con NAN builders". NaN API: base `https://api.nan.builders/v1`, `Authorization: Bearer <key>`, chat `POST /chat/completions` with model `deepseek-v4-flash`, STT `POST /audio/transcriptions` (multipart, `model=whisper`). Key in `.env.local` (`NAN_API_KEY`), server-only. Without a key, the app falls back to self-grading.
